# Wedding Photographer

💻 **About the Project** Wedding Photographer is a team-based educational
single-page web project developed as part of the JavaScript course. The project
was created to gain practical experience in developing a web application,
working with modern frontend development practices, and utilizing the Vite
bundler. It features a responsive design (Mobile First approach), an interactive
mobile menu, dynamic portfolio filtering, and a functional feedback slider
integrated with an external API.

🧰 **Technologies** HTML5 • CSS3 • JavaScript • Vite • Git • GitHub • GitHub
Pages • Axios • SwiperJS • modern-normalize • IziToast • Accordion

👥 **Teamwork** The project was developed collaboratively using Git and GitHub.
We worked with branches, resolved merge conflicts, and integrated code via pull
requests as part of the team development workflow, alongside task planning and
management using GitHub Projects.
